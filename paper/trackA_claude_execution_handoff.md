## 3. Regional candidate. Calibrate the decision to override

**Question.** Does a spatial score improve paired core-versus-infiltrating classification beyond composition, density, depth, and malignant expression, when a qualified independent reference measures the errors that both reconstructions can share?

1. Make a development specimen audit. For each pair, freeze an ID-based ordering before the labels are joined. Generate the same spatial statistic from vendor and fixed alternative reconstructions of the same section. Define an independent reference for the relevant margin error using registered annotations or orthogonal measurements. Specify what the reference actually measures, its uncertainty, and which acquisition conditions it covers. Establish independence of the region label from the prediction inputs. Keep label-defining pathology masks out of the predictor.
2. Fit the existing combined nonspatial model and shared spatial-margin model on fitting origins only. Preserve the current uncertainty-bound model as a baseline. Add a candidate that considers spatial evidence specifically when the two reconstructed decisions agree and would change the nonspatial decision. On separate development origins, choose or reject an override threshold using the harm rate among proposed overrides. Use a fixed threshold grid and a simultaneous one-sided bound over that grid, or choose a threshold on split A and validate it on independent split B. Keep the audit, minimum override count, and permissible harm ceiling explicit. A supported region with zero proposed overrides cannot earn a spatial contribution claim. An unsupported condition falls back.
3. Use the same pairs, training folds and feature availability for every arm. Compare with composition, density/depth, malignant expression, the combined nonspatial model, vendor and alternative reconstruction separately, segmentation-free molecule features, qualified contamination correction, the prior marginal bound, same-fit agreement without the audit, and the override model with the selective check removed. Add an identifiable geometry-only and shuffled-mark control using fixed geometry and strata. Record why any published method cannot be fairly adapted to the endpoint.
4. Predeclare one development falsification and fresh draws. Include shared and divergent errors, missed contamination, a mismatch between the calibration and evaluation conditions, density-only effects and clean signal. On each patient record the baseline decision, each reconstruction decision, the final decision, and whether the spatial evidence changed or worsened the call. Report changes and harms per proposed override and per enrolled patient. Assess actual classification losses against pathology on development patients when available. Reference-margin coverage is a technical diagnostic. The pathology label supplies the classification score.
5. Advance only if a single fixed candidate clears its prespecified development rules against the strongest baseline, shows an identifiable benefit from the safeguard, retains useful coverage and avoids excess override harm in the planned shift. If the calibration data are too sparse to support the decision, report the uncertainty and required sample count. If the reference misses the shared error, repair the measurement design before retesting.
6. If only whole-tissue or spot-level data qualify, freeze a distinct question, feature adapter and baseline manifest before opening them. A whole-tissue classifier can support a regional expression claim. The cell-neighbor claim requires cell-resolved evidence.

## 4. TMZ candidate. Test what true sister links add

**Question.** Does verified within-origin supervision add predictive information for a baseline-RNA model of measured TMZ viability on new origins and under an independent assay or lab shift?

1. Freeze the assay endpoint before comparing models. Prefer normalized viability AUC over a common, justified dose window and exposure time if compatible measurements exist. Record direction, interpolation, replicate aggregation and units. Reject treatment receipt and survival as outcome proxies. Average technical wells under an assay-specific rule. Use independently derived cultures for the contrast.
2. Keep the current one-slope contrast model as a comparator. Develop one distinct extension only after checking the closest group-aware regression and drug-response papers. One testable extension is to use an origin-centered model to propose an expression direction, then allow that direction into the origin-mean predictor only if its sign and added value replicate across disjoint development origins. Fit the ordinary expression predictor with the same features and tuning budget in all arms. Estimate the proposed direction and its stability inside each training fold. Keep the added coefficient and any fallback rule locked before external scoring. Treat this as a hypothesis until the claim chart and the ablation support it.
3. Compare with MGMT where available, culture-weighted and origin-balanced ridge, elastic net, origin means alone, the existing contrast loss, the fixed source score, and a predeclared family of matched random signatures. Include an outcome-blind feature-direction control, the same model with the within-origin direction removed, and training-only repeats with sister links shuffled within compatible strata. Preserve whole culture-level expression–outcome rows and group sizes during shuffling. Keep whole origins out of tuning and evaluation folds. Freeze any missing-MGMT strategy and any MGMT-complete sensitivity cohort in advance.
4. Test the mechanism on fresh development fixtures. Include a setting with real cross-origin transfer of the within-origin direction, a setting where between-origin effects reverse that direction, unequal sister counts, an assay shift that changes noise, and a null. Compare true and shuffled-link arms with the same splits. Check that the baseline can win if the assumptions fail. A development result that equals a tuned ridge fit or survives link destruction at the same level leaves the sister-link mechanism unproven.
5. Report absolute error of mean viability for each held-out origin as the proposed primary endpoint. Compare every arm on those same origins. Report secondary within-origin contrast error on eligible repeated origins, calibration, number of cultures, assay coverage and sensitivity to lineages. Keep those secondary results distinct from the primary claim. If only singleton origins qualify, the sister-learning study stays blocked. A separate single-culture prediction study needs its own claim and protocol.

3. **Fix numerical gates before opening the test.** Fill in the minimum meaningful primary gain, minimum gain over the ablation, minimum gain or allowed degradation under the shift, required coverage, maximum harm and analysis level. 4. **Program the pass rule and size that rule.** Use paired intervals for mean improvement and simultaneous coverage over the frozen comparison family. Estimate joint power for the actual decision rule under reasonable alternatives and adverse assumptions, using permitted development estimates of ties, paired variance, comparator dependence, assay differences and attrition.
