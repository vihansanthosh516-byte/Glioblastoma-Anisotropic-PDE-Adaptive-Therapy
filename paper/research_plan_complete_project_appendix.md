# Reproduction appendix: complete GBM Tracks A, B, and C plan

This appendix gives one integrated account of the project from its data inputs through analysis and interpretation. Each part states the selected method and places existing evidence and its main limit beside that method. Results from earlier analyses are exploratory, not preregistered or untouched confirmation.

## Project question and scope

The primary question is whether a hierarchical state-space model can improve next-scan prediction of postoperative GBM volume by representing latent net growth separately from MRI measurement error. The project also brings together three GBM workstreams: Track A studies molecular tumor-zone labels, Track B studies MRI growth and recurrence location, and Track C studies treatment schedules in simulation. The cohorts do not have a verified patient-level link, so we need to analyze them as related but separate modules. We must not describe them as one fused patient-specific model or a validated digital twin.

The published Abu Khalaf repeatability study may inform a sensitivity assumption in the MRI model; it is not a measurement of error in this project’s scans.

## Shared data and analysis rules

We need to treat the patient as the unit for splitting, resampling, and reporting; construct a visit table that links only records with explicit dataset identifiers; document exclusions and missing visits; and keep measured patient-data estimates, simulations, model assumptions, and model-derived quantities distinct. We need to preserve a manifest for each source with its exact release, URL, file list, file-level license, citation, and exclusions. The article’s license does not automatically establish the license for every data file. For each selected method, we need to report any existing estimate beside its source output, label reused test cohorts as exploratory, and place the main weakness beside each conclusion.

## Track A — Patient-level molecular tumor-zone prediction

**Question.** Do molecular features predict Core, Periphery, or Healthy labels for cells from patients not used for model fitting?

We need to use the UCSC multiomic-gbm atlas and split by donor, not by cell. The source paper reports 223,113 cells from 25 patients; the project’s filtered object contains 140,355 cells. The existing donor-grouped split has 16 training, 3 validation, and 5 test patients. We need to reconcile the unmatched donor against the source manifest using a fixed identifier rule. Preserve the existing assignments for every resolved donor and exclude an unresolved donor without reshuffling; freeze the resulting eligible split before the final comparison. We need to fit the attention-gated classifier using training and validation donors only, compare it with fixed PCA-50/logistic regression and a 200-gene logistic-regression panel, and report macro-F1 plus donor-level uncertainty. Existing five-seed estimates are 0.729 for attention, 0.765 for PCA/logistic regression, and 0.710 for the panel. The PCA-minus-attention difference is +0.036, with a seed-42 bootstrap interval from −0.009 to +0.064; the panel-minus-attention interval is −0.042 to −0.003. These estimates are exploratory; the intervals use one seed’s predictions and do not include all training-seed variation. The five-patient test group comes from one atlas, donor and class composition may be confounded, and normalized counts limit methods that require raw counts. Because this cohort informed model development, the final corrected comparison is also exploratory, not external validation. Values come from output/patient_split_v2_methods/summary.json and comparison.json.

## Track B — MRI growth forecasting and reaction-diffusion

**Question.** Does the spatial reaction-diffusion forecast improve next-scan tumor-mask prediction over persistence and a simple population-growth rule?

We need to use eligible postoperative masks in MU-Glioma-Post, generate patient-level out-of-fold predictions with the 2 mm positivity-preserving solver, select parameters only within training folds, and score the same forecast pairs with Dice against persistence and the population geometric-growth rule. We need to report paired patient-level differences and intervals, with the tensor-direction comparison as secondary. The exploratory anisotropic global-z result for 133 patients gives PDE-minus-persistence Dice +0.0106 (95% CI −0.0043 to +0.0259) and PDE-minus-geometric-training-rate Dice −0.0029 (95% CI −0.0166 to +0.0111); neither interval excludes zero. For LUMIERE, the exploratory volume-only growth forecasts were worse than no-change for both automated tools (reported p = 0.0003 and p = 0.004). These cohorts informed earlier development, so these estimates are not fresh confirmation. The PDE did not beat the simple geometric baseline, and segmentation and tumor definitions differ among cohorts; numerical solver checks do not establish biological validity. Sources are output/pde_manifest/results.json, output/lumiere_volume_forecast.json, and findings-ledger entries 2y and 2ak.

## Track B — Recurrence location and the 15 mm margin

**Question.** At equal target volume, does the model-derived recurrence-risk map cover later enhancing recurrence better than a 15 mm expansion?

We need to evaluate the selected equal-volume recurrence-map procedure without using target-cohort recurrence labels as model inputs. For LUMIERE/RHUH, use the H-2 `hybrid_rank_mu` model trained for 15 epochs with seed 20261009 on 142 TUM development patients and 334 MU pairs; its inputs are core, edema, white matter, gray matter, CSF, brain, distance, and M1-density channels. For the separate UCSF sensitivity cohort, use the H-3 `hybrid_mri_rank_mu` model trained on the same development sets for 15 epochs with the same seed and with T1c/FLAIR channels added. Use each saved model state and its preoperative-only 2 mm logits, upsample the logits to 1 mm, apply sigmoid, then select the highest-scoring voxels inside the brain until the predicted region has the same volume as the 15 mm standard plan. Do not refit on the target cohorts. Score enhancing recurrence as primary and all recurrence as secondary. Existing exploratory LUMIERE/RHUH estimates give an enhancing-recurrence coverage difference of +0.0088 (95% CI −0.0115 to +0.0307; n = 98) and an all-recurrence difference of +0.081 (95% CI +0.065 to +0.097; n = 101). Existing UCSF estimates give an enhancing difference of +0.0044 (95% CI −0.0182 to +0.0369; n = 49) and an all-recurrence difference of +0.085 (95% CI +0.059 to +0.115; n = 59). The primary enhancing-recurrence endpoint is inconclusive in both cohorts. The 2026 PREDICT-GBM paper evaluates the same general recurrence-planning problem and a 15 mm comparator, so we need to use it as prior-art context and describe our result as a project-specific exploratory replication, not a new recurrence-margin method. The reused cohorts cannot provide fresh confirmation, and the secondary all-recurrence result does not establish clinical benefit. Model specifications and outputs are in scripts 122–123 and `output/predictgbm/final/`, and scripts 132–133 and `output/predictgbm/h3_final/`.

## Track C — Treatment policy under assumed drug effects

**Question.** Under an explicit sensitive/resistant-cell model, how do adaptive and standard schedules trade off modeled tumor burden, progression time, dose, and resistance?

We need to use the two-population treatment simulator with growth parameters fitted from the MRI cohort and kill rates explicitly treated as assumptions. We need to compare adaptive and standard maximum-tolerated-dose (MTD) schedules under the stored E_MAX-to-growth ratio grid of 500, 1000, and 2000, and report final burden, progression time, resistance, dose, and censoring at every ratio. The existing result at the illustrative ratio of 1000 has a higher modeled resistant fraction under MTD in 54 of 61 cases, 7 ties, a mean patient-level adaptive/MTD ratio of final total mass of 2.39, earlier progression under adaptive treatment in 10 of 61 cases, and 39 cases censored in both arms. The ratio-1000 example does not replace reporting the full grid. The scale is assumed, not a measured drug effect. The separate MU-Glioma-Post MGMT analysis has 130 patients, median times to progression of 169 versus 181 days, and log-rank p = 0.60; it is an observational association, not a treatment-effect estimate. The main limit is the lack of patient-level drug dose, timing, and response data to estimate individual kill rates, so the simulation cannot support a clinical recommendation or patient-specific benefit. Sources are output/emax_sweep_summary.json and output/mgmt_resistance/results.json.

## New mathematical model — measurement-aware state-space growth

**Question.** Can a model that separates latent net postoperative volume trend from scan measurement error improve next-scan prediction over a training-fold population-median log-volume slope (primary), with persistence as a secondary comparator, and how strongly can the available data constrain its noise and net-growth parameters?

We need to evaluate this as the proposed new method; the training-fold population-median slope is its primary prediction comparator, and persistence is secondary. Its weakest point is that no project-specific scan-rescan noise estimate exists, so measurement error may remain confounded with true net volume change even if the model fits well. We need to compare the method with prior work before describing it as novel.

We need to use positive postoperative segmented volume \(V_{ij}\) at visit \(j\) for patient \(i\), transform it to \(y_{ij}=\log V_{ij}\), and require at least three visits with positive volume and known scan day. Define volume as the count of voxels with any positive tumor-mask label multiplied by physical voxel volume. Use the recorded MRI day from the clinical visit table to calculate \(\Delta t_{ij}\); exclude a patient with fewer than three valid dated visits without relaxing the rule after seeing results. Let \(x_{ij}\) be latent log volume. We need to treat the first latent state for each patient as an unrestricted patient-specific intercept and integrate it with exact diffuse Kalman initialization. It is a nuisance state, not a population parameter, so it is not included in the Laplace intervals. We need to use the observation equation

\[
y_{ij}=x_{ij}+\epsilon_{ij}, \qquad \epsilon_{ij}\sim N(0,\sigma_e^2),
\]

and the transition equation

\[
x_{i,j+1}=x_{ij}+g_i\Delta t_{ij}+\eta_{ij}, \qquad
\eta_{ij}\sim N(0,\sigma_w^2\Delta t_{ij}), \qquad
g_i\sim N(\mu_g,\tau_g^2).
\]

Here \(g_i\) is the patient’s net postoperative log-volume trend across the observed care pathway; it is not untreated biological growth. The primary observation model assumes independent, equal-variance scan errors across visits. We need to assume that observation errors are independent across visits and patients, that process innovations are independent across intervals and patients, and that both are independent of each patient’s slope and initial state. We need to treat the external repeatability scale checks as sensitivity assumptions only; they do not measure correlated or site-specific errors in these cohorts. We need to omit a treatment-phase term from the primary model because treatment timing is incomplete or inconsistently recorded across cohorts. This avoids assigning unverified treatment states and prevents an assumed drug coefficient from being mistaken for an estimated effect.


We need to augment the Kalman state with the patient-specific slope \(g_i\), hold that slope constant across visits, and marginalize both latent volume and slope in the linear-Gaussian likelihood. Let \(z_{ij}=(x_{ij},g_i)^\mathsf T\); initialize \(x_{i1}\) with the exact diffuse Kalman method and assign \(g_i\sim N(\mu_g,\tau_g^2)\), independently of \(x_{i1}\). The augmented transition is

\[
z_{i,j+1}=\begin{bmatrix}1&\Delta t_{ij}\\0&1\end{bmatrix}z_{ij}+\begin{bmatrix}\eta_{ij}\\0\end{bmatrix}.
\]

We need to estimate the population parameter vector \((\mu_g,\tau_g,\sigma_w,s_\Delta)\) by maximum a posteriori optimization, integrating out each patient’s diffuse initial state and marginalizing patient-specific slopes in the linear-Gaussian likelihood. Use a Laplace approximation around the mode for intervals on these four population parameters; do not include diffuse initial states in the parameter intervals. We need to set \(\mu_g\sim N(0.002,0.005^2)\), \(\tau_g\sim\mathrm{HalfNormal}(0.01)\), and \(\sigma_w\sim\mathrm{HalfNormal}(0.05)\). These are modeling assumptions. We need prespecified prior-sensitivity fits: change the slope prior to \(\mu_g\sim N(0,0.01^2)\), and one at a time change the half-normal scales for \(\tau_g\) to 0.005 and 0.02 and for \(\sigma_w\) to 0.025 and 0.10. We need to report every sensitivity result, not select a favorable prior. A fit is usable only when optimization converges, the log posterior is finite, and the negative Hessian at the mode is positive definite; otherwise we need to report a fit failure and make no Laplace-interval claim. The slope parameters \(\mu_g\) and \(\tau_g\) are in log-volume units per day, \(\sigma_w\) is in log-volume units per square-root day, and \(\sigma_e\) is in log-volume units.

The measurement-error scale is not observed in MU-Glioma-Post or LUMIERE. We need to define \(s_\Delta\) as the standard deviation of error in a two-scan log-volume difference. Under independent, equal-variance scan errors, we need to set \(\sigma_e=s_\Delta/\sqrt{2}\). The primary patient-data fit estimates \(s_\Delta\) under the prior \(s_\Delta\sim\mathrm{LogNormal}(\log(0.115),0.4)\). Separate endpoint sensitivity fits fix \(s_\Delta\) at 0.079 or 0.342 and omit its prior from the optimization. These values use an ambiguous conversion of Abu Khalaf et al.’s published repeatability coefficients and are not project-specific noise estimates. We need to compare the prior-based result with both endpoint fits and report the three results; the endpoint checks do not imply a dense sweep over the interval.

Before fitting patient outcomes, we need to run 200 parameter-recovery simulations at each of three fixed noise scales \(s_\Delta\in\{0.079,0.115,0.342\}\) (600 datasets total). For each replicate, preserve the eligible patients’ actual visit times and set each patient’s fixed latent starting value to that patient’s first observed log-volume; draw patient slopes from \(N(0.002,0.01^2)\), set \(\sigma_w=0.05\), and generate independent process and observation errors with \(\sigma_e=s_\Delta/\sqrt{2}\), including observation error at the first visit. This checks recovery conditional on the chosen starting values and schedules; it does not estimate the distribution of starting volumes or whether the model can distinguish first-scan error from initial-state uncertainty. Use seeds 41000–41199 for the central setting, 41200–41399 for the lower endpoint, and 41400–41599 for the upper endpoint. Estimate \(s_\Delta\) in every fit under the same lognormal prior centered at 0.115, including fits to endpoint-generated data; use each fixed generating scale as the truth for recovery scoring, not as a fixed fitted value. For each replicate, form 90% Laplace intervals for \(\mu_g\) on its identity scale and positive parameters on the log scale; report coverage and exact binomial 95% intervals for \(\mu_g\), \(\tau_g\), \(\sigma_w\), and \(s_\Delta\) separately by noise setting. Also report derived \(\sigma_e=s_\Delta/\sqrt{2}\); its interval coverage is equivalent under this fixed scale transformation. An interval containing 0.90 means the observed coverage is compatible with nominal coverage, not that calibration has been proved. Poor coverage means the fitting and recovery procedure failed; it alone does not prove non-identifiability. To assess separation in patient data, we also need three pairwise profile-likelihood surfaces: (scan-error SD, process-noise SD), (scan-error SD, slope SD), and (process-noise SD, slope SD). Use 21 equally spaced log-scale values spanning the central 95% prior quantiles for \(\sigma_w\) and \(\tau_g\); for \(\sigma_e\), map the central 95% prior quantiles of \(s_\Delta\) through \(\sigma_e=s_\Delta/\sqrt{2}\). For each of the three parameter pairs, use a 21-by-21 grid: fix the displayed pair at each grid point and maximize the likelihood without priors over the population mean slope and the remaining variance parameter. When the scan-error SD is fixed, set the two-scan difference-error SD to sqrt(2) times that value. These are descriptive diagnostics, not formal confidence regions. We need to report any broad trade-off ridge as evidence that the data do not sharply separate the relevant variance components; we must not claim a formal identifiability proof. Simulation recovery failure will be reported separately. Self-generated recovery cannot prove identifiability in real scans.

For prediction, we need to create five patient-grouped folds once using seed 4200 and reuse them for every model. In each fold, fit the state-space population parameters using training patients only. Estimate the population-median patient slope as the median of least-squares log-volume slopes for all eligible training patients with at least two distinct scan days; report any patients omitted because no slope is estimable. For a held-out patient, persistence predicts the previous log volume; the population-slope baseline predicts the previous log volume plus the training-fold median slope times elapsed days. Estimate each baseline residual variance from its pooled one-step residuals among training patients only, and use a Gaussian predictive density for each held-out next log-volume. For the state-space model, initialize from the first eligible visit, then update using only visits observed before each one-step-ahead prediction; include latent-state and Laplace parameter uncertainty in its predictive density. Within each held-out patient, average paired state-space-minus-population-slope log-score differences across forecast visits; also calculate the paired difference against persistence as a secondary comparison. The primary effect is the median of these patient-level averages; use a 2,000-resample patient bootstrap with seed 4201 and a percentile 95% interval. Repeat both forecast comparisons under the prespecified slope and process-noise prior sensitivities. Because this cohort informed earlier project growth analyses, these folds provide exploratory internal validation, not an untouched confirmatory test. Define each score difference as model minus comparator, so higher is better. Support requires a positive median and an interval wholly above zero against the primary population-slope baseline; a sign change under a prespecified prior sensitivity means the result is prior-sensitive. We need to report predictive-interval coverage, calibration, exclusions, and the secondary comparison against persistence. LUMIERE is only a cross-cohort sensitivity check because its feature tables were used in earlier analyses; tumor definitions and measurement pipelines differ. The main weakness is that simulation recovery tests the model on data generated by itself, while published repeatability data come from another cohort, scanner, and segmentation tool.

## Integrated interpretation

We need to place the results in one evidence table with one row for each track or new method. Each row needs the question, dataset and release, endpoint, estimate and interval, source output, evidence type, and main limit. The table must show that the recorded attention model did not establish a gain over PCA/logistic regression; the PDE forecast did not establish a gain over simple growth; the recurrence primary endpoint was inconclusive on reused cohorts; and treatment-policy results are simulation-only. We need to determine the state-space model result from the specified recovery and prediction analyses, then report it with its uncertainty and failure mode. The final conclusion must say whether the data support any module and must state that no linked patient-level omics-to-MRI model or validated digital twin was established.

## Feasibility and limits

The state-space likelihood uses a Kalman filter over visit sequences, so fitting scales with the number of visits rather than image voxels and should fit the stated desktop. The simulation recovery study and patient-level folds will require repeated fits; their runtime has not been benchmarked. The full UCSF-PDGM release is large, but the state-space primary analysis uses MU-Glioma-Post and does not require downloading every source in the inventory. We need at least 50 eligible MU patients for the five-fold forecast comparison, giving an average of 10 held-out patients per fold; this is an operational minimum, not a power guarantee. If fewer qualify, report the count and stop the fold-based comparison rather than relax eligibility; descriptive results may be reported without an inferential improvement claim. The major scientific limit is that existing cohorts cannot independently measure scan error, untreated growth, and treatment response.
