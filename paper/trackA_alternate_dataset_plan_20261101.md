# Track A no-contact alternate dataset plan

**Status:** Plan only (2026-11-01, fourth metadata follow-up). No one was contacted. No new expression values were opened and no new expression data were downloaded. No new score was run. No figure was changed. This plan does not authorize data access or scoring. E-MTAB-8743 has prior project use, documented below.

## Aim

The primary Track A question remains whether the already frozen malignant-cell Core/Periphery signature transfers to independent patient samples. The strongest current external RNA candidate is the SNUH-GliomaAtlas (Park et al., 2026): its final paper reports six biologically independent GBM patients with matched core and periphery single-cell samples. Public sample metadata identifies six paired IDH-wildtype GBM donors, and the atlas provides cell annotations including neoplastic classes. The paper already analyzes this regional contrast; any use would be a separate replication, not a novelty claim. Do not add outside data to the current figure.

Harwood et al. has seven paired GBM cases but studies the same p53-positive core/infiltrated contrast and its workbook crosswalk remains unchecked. The Dryad IMC cohort has seven exact core/edge donors but measures proteins, not RNA. Any future use must have its own dated amendment and separate display. These candidates support replication, not a novelty claim based on rediscovering the published regional contrast.

## No-contact gates for any candidate

1. Read public metadata only. Verify donor/sample/region links, diagnosis and IDH status, complete paired regions, and the exact eligible donor count. Do not infer pair counts from total atlas size or a study-level statement alone.
2. Verify the exact processed/raw files and the record-level terms. If an account approval, access application, or person-to-person request is required, stop. If use terms remain unclear, stop without contact.
3. Compare patient and sample identifiers with Track A's training and prior-use records. Stop if there is overlap or prior scoring. E-MTAB-8743 already fails this gate. Targeted text searches found no recorded prior use of GSE317289, Zenodo 10521687, GSE153746, GSE197543, or GSE232469; this does not rule out unrecorded exposure or prior use without accession labels.
4. If those gates pass, prepare and commit a dated amendment before opening expression values. Freeze the endpoint, controls, code, and interpretation limits. Obtain the user's go-ahead before any expression-data download or scoring.
5. Keep the evidence type explicit. E-MTAB-8743 can support only a donor-level bulk-tissue Core-versus-Invasive-margin replication; it cannot validate a malignant-cell-only result. A cell-level validation requires a separate cohort with a defensible malignant-cell label. Treat each patient as one analysis unit and report every eligible paired value.
6. Keep any future result descriptive. Do not add outside data to the current figure; any display would need a separate, clearly sourced figure.

## Current decision

**Top conditional candidate: SNUH-GliomaAtlas; no data access yet.** The final paper reports six matched GBM Core/Periphery patients, public sample metadata identifies six IDH-wildtype pairs, and the paper links processed single-cell data with cell annotations without restricted access. The atlas itself analyzes regional differences, so any use is a separate replication with a separate figure. Dataset-specific reuse terms, exact matrix structure, and patient overlap with prior project work remain unchecked. Harwood remains a secondary option, but its paper already analyzes the same p53-positive core/infiltrated contrast and its workbook crosswalk is unchecked. No outside data were added to the current figure. This follow-up read public papers and metadata only: no one was contacted, no expression values were opened, no new expression file was downloaded, no score was run, and no figure was changed. The existing access gate requires the user's go-ahead before expression-data download; a dated amendment is required before scoring.

## Search coverage and limits

This targeted metadata screen checked NCBI GEO, GSA-Human, EGA, Dryad, BioStudies/ArrayExpress (including E-MTAB-8743), Zenodo, Synapse, the final SNUH-GliomaAtlas paper and its public data links, plus linked source papers. This follow-up rechecked SNUH-GliomaAtlas, Harwood/Zenodo 10521687, and the 2025 needle-biopsy spatial cohort GSE287631; the latter's multi-omics spatial analysis centers on one patient and does not meet the donor floor. It also considered previously screened GSE182109, GSE153746, GSE197543, GSE232469, GSE317289, and GSE318562. It read public paper text, record metadata, and sample annotations only; it did not read or download new expression or sequence data. The existing E-MTAB-8743 author count matrix and analysis are prior project work, not part of this follow-up. It did not exhaustively search HCA, HTAN, CPTAC, OSF, or every Figshare and Zenodo record. Do not describe the search as exhaustive.
