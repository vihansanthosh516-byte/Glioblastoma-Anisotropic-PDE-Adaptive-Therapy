# Track A no-contact alternate dataset plan

**Status:** Plan only (2026-11-01, eighth metadata follow-up). No one was contacted. No expression matrix was opened and no new expression data were downloaded. No new score was run. No figure was changed. This follow-up checked Harwood's published sample map and the Zenodo record/API metadata only. This plan does not authorize expression access or scoring. E-MTAB-8743 has prior project use, documented below.

## Aim

The primary Track A question remains whether the already frozen malignant-cell Core/Periphery signature transfers to independent patient samples. SNUH-GliomaAtlas (Park et al., 2026) is not a new holdout: six matched SNU donors already appear in the local donor manifest and prior seven-donor exploratory audit. Harwood et al.'s public GeoMx cohort now passes the published-design and record-level access gates: the paper identifies seven paired IDH-wildtype cases, and the Zenodo API reports an open CC BY 4.0 record. The workbook's own sample labels remain unchecked because that workbook may contain expression data. Keep all outside data out of the current figure. Any future analysis needs its own figure and supports replication only, not a novelty claim.

## No-contact gates for any candidate

1. Read public metadata only. Verify donor/sample/region links, diagnosis and IDH status, complete paired regions, and the exact eligible donor count. Do not infer pair counts from total atlas size or a study-level statement alone.
2. Verify the exact processed/raw files and the record-level terms. If an account approval, access application, or person-to-person request is required, stop. If use terms remain unclear, stop without contact.
3. Compare patient and sample identifiers with Track A's training and prior-use records. Stop if there is overlap or prior scoring. E-MTAB-8743 already fails this gate. SNUH-GliomaAtlas fails as a new holdout: six SNU donors appear in local donor summaries, and a prior seven-donor exploratory audit used the same processed object. Targeted text searches found no recorded prior use of GSE317289, Zenodo 10521687, GSE153746, GSE197543, or GSE232469; this does not rule out unrecorded exposure or prior use without accession labels.
4. If those gates pass, prepare and commit a dated amendment before opening expression values. Freeze the endpoint, controls, code, and interpretation limits. Obtain the user's go-ahead before any expression-data download or scoring.
5. Keep the evidence type explicit. E-MTAB-8743 can support only a donor-level bulk-tissue Core-versus-Invasive-margin replication; it cannot validate a malignant-cell-only result. A cell-level validation requires a separate cohort with a defensible malignant-cell label. Treat each patient as one analysis unit and report every eligible paired value.
6. Keep any future result descriptive. Do not add outside data to the current figure; any display would need a separate, clearly sourced figure.
