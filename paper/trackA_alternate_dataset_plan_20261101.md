# Track A no-contact alternate dataset plan

**Status:** Plan only (2026-11-01, metadata follow-up). No one was contacted. No new expression data were opened or downloaded. No new score was run. No figure was changed. This plan does not authorize data access or scoring. E-MTAB-8743 has prior project use, documented below.

## Aim

The primary Track A question remains whether the already frozen malignant-cell Core/Periphery signature transfers to independent patient samples. No screened dataset currently passes the primary confirmation gates. E-MTAB-8743 was already used in the project; GSE317289 is only a five-patient tissue-level spatial lead and cannot answer the malignant-cell-specific question. Do not claim a new core-edge discovery or add outside data to the current figure.

## No-contact gates for any candidate

1. Read public metadata only. Verify donor/sample/region links, diagnosis and IDH status, complete paired regions, and the exact eligible donor count. Do not infer pair counts from total atlas size or a study-level statement alone.
2. Verify the exact processed/raw files and the record-level terms. If an account approval, access application, or person-to-person request is required, stop. If use terms remain unclear, stop without contact.
3. Compare patient and sample identifiers with Track A's training and prior-use records. Stop if there is overlap or prior scoring. E-MTAB-8743 already fails this gate. A targeted accession search found no prior expression-level use of GSE317289 in `src/`, `output/`, or `data/manifests/`; this is not a full-project history audit.
4. If those gates pass, prepare and commit a dated amendment before opening expression values. Freeze the endpoint, controls, code, and interpretation limits. Obtain the user's go-ahead before any expression-data download or scoring.
5. Keep the evidence type explicit. E-MTAB-8743 can support only a donor-level bulk-tissue Core-versus-Invasive-margin replication; it cannot validate a malignant-cell-only result. A cell-level validation requires a separate cohort with a defensible malignant-cell label. Treat each patient as one analysis unit and report every eligible paired value.
6. Keep any future result descriptive. Do not add outside data to the current figure; any display would need a separate, clearly sourced figure.

## Current decision

**No-go for a new primary malignant-cell confirmation; download nothing.** E-MTAB-8743 is already used and scored in the Track A TAM exploration, so it is not independent. Its sample metadata confirms 10 donor-level Core/Rim/Invasive sets, but ENA's `SINGLE` layout conflicts with the paper's paired-end description; the 50-run raw set totals 119.6 GiB. GSE317289 is a new public no-contact lead with 10 IDH-wildtype GBM spatial samples from five patients, but it is below the six-donor floor, its complete pair map remains to verify, and GEO has no linked citation. It could be considered only for a separately amended exploratory spatial description. SNUH-GliomaAtlas has six matched pairs overall but only five strict IDH-wildtype GBM pairs in the preprint supplement; its raw data are described as available upon request, so it is not a current no-contact primary candidate. HRA005318 and GSE84465 have only three and four exact pairs. No screened alternative currently passes every gate for primary malignant-cell confirmation. This follow-up read public record and sample metadata only: no one was contacted, no expression values were opened, no raw/sequence file was downloaded, no score was run, and no figure was changed.

## Search coverage and limits

This targeted metadata screen checked NCBI GEO, GSA-Human, EGA, Dryad, BioStudies/ArrayExpress (including E-MTAB-8743), the SNUH-GliomaAtlas site and linked GitHub, plus linked source papers. The follow-up also screened GSE182109, GSE317289, and an eight-patient Dryad imaging-mass-cytometry cohort. This follow-up read public record and sample metadata only; it did not read or download new expression or sequence data. The existing E-MTAB-8743 author count matrix and analysis are prior project work, not part of this follow-up. It did not exhaustively search HCA, HTAN, CPTAC, OSF, or every Figshare and Zenodo record. Do not describe the search as exhaustive.
