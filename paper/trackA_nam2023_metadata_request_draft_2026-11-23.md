# Draft: metadata-only request to the Nam et al. 2023 team (NOT SENT)

**Source facts (from the article, [PMC10010007](https://pmc.ncbi.nlm.nih.gov/articles/PMC10010007/)):** 52 tumour sectors from 18 cases; multisector GSCs screened with TMZ (7-point 4-fold dilution, 500 µM to 122 nM, 6 days, ATP luminescence; GR50 and AUC); RNA-seq on 26 multisector samples; data in EGA EGAS00001006989 (controlled). Corresponding authors listed: Jiguang Wang (jgwang@ust.hk), Yeup Yoon (benedict.yoon@samsung.com), Hye Won Lee.

**Why this source fits:** several independently derived cultures per tumour with a common TMZ assay is exactly the structure the TMZ lane needs. If counts qualify, it would be a development source (published data, so not a fresh external test).

2. Were the RNA-seq and the TMZ assay done on the same culture and passage window, before any drug exposure?
3. Was the TMZ assay (dose range, 6-day ATP readout, GR50/AUC) the same for the multisector cultures and the main 69-culture panel?
4. Are all multisector cases primary, treatment-naive tumours? Is MGMT promoter status available per case?
5. Does EGA contain a coded case-to-sector-to-culture key, and which data access committee and terms apply?
