# HGCC temozolomide-response bridge: source correction and proposed protocol

**Status: proposed. No HGCC TMZ outcome was analyzed.** This record corrects the earlier statement that HGCC had no measured TMZ response. It also records a limited browser-access deviation. The protocol below is not a result and does not change A5.

## Source correction

The 2025 Ju et al. study reports 83 HGCC glioblastoma cell-culture microarray profiles paired with measured TMZ area-under-the-response-curve (AUC). It trains and evaluates response-prediction models on HGCC with five-fold cross-validation and also uses HGCC in transfer-learning experiments. This is substantial prior art; this project must not claim the first HGCC TMZ-response model. The current HGCC resource page describes 48 cell lines. Therefore, the paper's 83 profiles must not be treated as 83 independent patient origins. The exact profile-to-line-to-origin map, including repeated assays and sublines, remains unverified.

The official [HGCC data portal](https://hgcc.se/portal/) states that it contains genomic and drug-response data and offers a drug-response download. The official [HGCC resource page](https://www.hgcc.se/) describes its cell-line data as an open resource and currently lists 48 cell lines. These pages do not state a clear license for the downloadable response table or rules for sharing derived outputs. The article's CC BY 4.0 license does not automatically establish the portal data's license. Use no raw values in shared files unless the data terms are verified.

The 2025 study's [public code](https://github.com/ErasmusMC-Bioinformatics/two-step-TL/blob/main/HGCCpreprocess.R) names separate HGCC expression and TMZ-AUC files. Its preprocessing script matches response IDs by truncating to five characters and averages duplicate outcomes. That is evidence a paired analysis was performed, but it is not enough to adopt the same join blindly: current portal IDs include replicate and subline suffixes. A metadata-only crosswalk must prove which records represent the same cell-line origin. Prefix-only matches are prohibited unless an authoritative data dictionary confirms them.

The proposed Track A question is narrower than the published deep-learning work: does the already frozen Ntafoulis-derived 119-gene directional score rank TMZ AUC among HGCC biological origins, after metadata confirms those origins do not overlap the Ntafoulis cultures that supplied the response directions? This origin-level independence is not yet established. Even if confirmed, the analysis would be a secondary reanalysis of a published response dataset, not an untouched external validation of the HGCC cohort. It would test an in-vitro response-associated score. It would not establish patient drug resistance, clinical response, or a connection to MRI or Track C.

## Prior-work boundary

Ntafoulis et al. (2023) derived response-associated gene directions from patient-derived cultures and reported the 121-gene overlap panel used by this project. The project froze a 119-of-121 mapped score and already applied it to A5 tissue as an exploratory regional proxy. Ju et al. (2025) later trained and evaluated response-prediction models on HGCC and used HGCC in transfer learning. Therefore, this proposed test is a fixed-signature association reanalysis of a previously published dataset, not a new drug-response modeling method, untouched external validation, or cohort discovery.

## Proposed protocol

1. **Cohort and join.** Use the published HGCC expression and TMZ-response files only. First inspect file names, headers, feature identifiers, sample identifiers, and documented replicate relationships. Read no TMZ response magnitudes during this inventory. Join by exact culture identifiers or an authoritative crosswalk; do not use five-character prefix matching by itself. Map each profile to its parent tumor origin. If multiple profiles/assays map to one origin, retain them only when metadata confirms compatible pretreatment expression and the same TMZ assay/dose range; calculate the score per expression profile, average matched repeat AUCs within culture, then average culture-level score and AUC within parent origin. If measurements are not comparable or cannot be paired exactly, stop rather than guess. Treat one parent origin as one analysis unit. Require at least 25 distinct origins as a feasibility floor, not a power guarantee. Verify no parent-origin overlap with the Ntafoulis cultures used to derive the score directions; if the mapping is unavailable or any overlap is found, do not call the analysis independent of the score-source cohort.
2. **Expression score.** Apply the existing frozen 119-gene set and its original directions without refitting, substitutions, or gene selection. Use the already normalized HGCC expression matrix; do not normalize or select genes from response values. Within each profile, rank all uniquely mapped measured genes and calculate the frozen score: mean percentile rank of the 47 resistance-associated genes minus mean percentile rank of the 72 sensitivity-associated genes. Require exact, unique mapping of all 119 frozen genes; otherwise stop. This is a cross-platform application of the fixed rank score, not a refitted model.
3. **Outcome.** Use the source-provided TMZ viability AUC only after the protocol and all metadata gates are frozen. Higher AUC represents more viability under drug exposure in this assay. Ju et al. caution that AUC values are not absolute or directly comparable across datasets because dose ranges and curve-fitting methods differ. Therefore analyze ranks within HGCC only; do not combine HGCC AUC with AUC from another study or convert it into a clinical resistance label.
4. **Primary analysis.** Calculate the Spearman correlation between the fixed score and TMZ AUC across unique biological origins, not profiles or assay repeats. Test the source-predefined positive direction by permuting origin-level AUC values across origins (100,000 permutations; NumPy PCG64DXSM seed `20261112`; plus-one p-value). Calculate a percentile 95% bootstrap interval by resampling origins 10,000 times (PCG64DXSM seed `20261113`). The 25-origin threshold is a feasibility floor, not evidence of adequate power; if precision is poor, report the result as inconclusive.
5. **Comparisons.** Report MGMT-expression Spearman correlation on the same origins as a descriptive benchmark, not a claim of superiority over clinical MGMT-promoter methylation. For 1,000 signed gene-set controls, calculate each gene's mean and standard deviation across the origin-aggregated expression profiles, standardize those two features across genes (zero SD becomes 1), then match each of the 119 panel genes to one unused non-panel gene among its 20 nearest available genes by Euclidean distance; use a seeded random panel-gene order, lexicographic tie-breaking, and NumPy PCG64DXSM seed `20261114`. Preserve the 47 positive/72 negative directions in every panel. Build controls using expression only, before outcome access; compare their origin-level correlations with the fixed score descriptively. MGMT and control comparisons are secondary and do not create extra pass conditions.
6. **Decision and claims.** Report the primary correlation, one-sided permutation p-value, and origin-bootstrap interval as observed. There is no composite pass rule and no requirement to outperform MGMT or a selected control panel. If the direction is positive and the prespecified test supports association, describe only an in-vitro association in this previously published HGCC dataset; otherwise report null, negative, or inconclusive findings unchanged. This result cannot repair A5's failed rule, validate a patient-specific resistance test, support clinical benefit, link a culture to a Track B patient, or reopen stopped Track C evaluation.
7. **Outputs and terms.** Keep expression and response files out of Git. Save only aggregate statistics, code and protocol hashes, source identifiers, and the verified sample-flow record, after data terms permit those outputs. Do not share raw response values or model weights.

## Scope-deviation record

On 2026-11-12, while checking whether the official portal exposed a downloadable response table, a browser action opened the combined HGCC drug-response matrix. The rendered preview exposed its column header and numeric response values for the first four non-TMZ drug rows. No TMZ row or TMZ value appeared in the preview. No file was saved locally, no values were copied or used, and no analysis was run. This was an unintended outcome-value exposure and is recorded here for audit. Any later TMZ analysis must freeze its protocol before opening or processing TMZ response values.

## Gates before outcome access

- Verify the exact HGCC expression/response release and its file hashes.
- Verify exact culture-to-expression joins, replicate handling, and at least 25 unique origins from metadata only.
- Verify exact coverage of the frozen 119 genes from feature identifiers only.
- Record the portal's data-use terms; the portal currently states public availability but no explicit license for the response download.
- Freeze the code, protocol, seed, and output rules before any TMZ response magnitude is read.

Until these gates pass, this remains a proposed analysis. Track B remains unchanged, Track C remains stopped, and no integrated patient-level claim is supported.
