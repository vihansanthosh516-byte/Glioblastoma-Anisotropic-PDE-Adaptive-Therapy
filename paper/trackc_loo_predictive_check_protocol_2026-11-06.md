# Track C: leave-one-out paired-signal prediction check

**Status: synthetic development protocol frozen; run not started.** This protocol tests whether peer-only model averaging predicts a held-out virtual patient's paired baseline signals. It is not a patient study, treatment-outcome test, or clinical-benefit test. The project title remains **“Integrating Tumor Biology and Longitudinal MRI for Glioblastoma Progression Modeling and In-Silico Therapy Optimization.”** Track A and Duke data are not linked to this Track C simulation.

## Question and advancement rule

For the simulator's assumed shared signal-generating model, will leave-one-patient-out (LOO) model averaging improve paired-signal log predictive density over (1) a fixed uniform mixture of the same 81 candidate models and (2) a matched conditional-independence model with the generating `q`, `a`, and `b` but `d=0`?

The LOO method will advance to a treatment-policy comparison only if, at **both n=18 and n=28**, its mean per-patient log predictive density is higher than both comparators in the primary informative-truth set and each of the four one-sided 98.75% t lower bounds is above zero. The 98.75% level applies a Bonferroni correction across the two contrasts at the two primary sample sizes. If any of the four bounds is zero or lower, the model will not advance as the primary policy method from this run. No parameter grid, threshold, or truth condition will be changed after results are seen.

## Frozen design

- **Truth anchors:** the seven previously specified signal truths: `(0.7,0.5,0.5,-0.5)`, `(0.7,0.5,0.5,0)`, `(0.7,0.5,0.5,0.5)`, `(0.9,0.5,0.5,0.5)`, `(0.5,0.5,0.5,0.5)`, `(0.7,0,0.5,0.5)`, and `(0.7,0.5,0,0.5)`. The primary informative set is the first, third, and fourth anchors: `q>0.5`, `a≠0`, `b≠0`, and `d≠0`. The remaining anchors are controls and will be reported separately.
- **`f0` ranges:** the three declared calibration ranges: low shift `(0.001·exp(-0.7), 0.1·exp(-0.7))`, default `(0.001, 0.1)`, and high shift `(0.001·exp(2.3), 0.9)`. The reference-normal control is omitted because the current predictive model assumes one of the calibration ranges.
- **Cohort sizes:** 18, 28, 100, and 500 virtual patients. The first two are primary; 100 and 500 show the learning curve and are secondary.
- **Replicates:** 25 root seeds per truth, `f0` range, and cohort size: 2,100 cohorts total. Roots are `20261905–20261929`, checked free within the existing Stage 2 development reserve. Each root is split deterministically by `f0`-range, truth, and size indices into separate `f0` and signal streams. No seed is used for a patient or treatment outcome.
- **Candidate:** all 81 frozen `(q,a,b,d)` points from `src/212_trackc_signal_fisher_grid.py`, with equal prior model weights. The shared-model weights for each patient are computed from the other patients' paired signals only. Each candidate signal density integrates `f0` with 256 Gauss–Legendre nodes over the known generating range. The method is given the correct `f0` range, an optimistic assumption.
- **Comparators:** (1) the same 81-point grid with fixed equal weights, (2) a fixed nominal model `(0.8,0.5,0.4,0.6)` from the existing signal-information protocol, (3) matched conditional independence using the generating `q,a,b` and `d=0`, and (4) the generating-parameter oracle. The oracle is a reference ceiling, not a deployable comparator. The matched conditional-independence control receives oracle knowledge of its nuisance parameters, favoring that comparator.
- **Primary score:** for each cohort, average natural-log predictive density per virtual patient. For the candidate, patient *i*'s score is the log mixture of that patient's marginal paired-signal densities using model weights fitted from all other patients. Higher is better. This is a held-out signal-prediction score, not a treatment utility.
- **Primary contrasts:** LOO minus fixed uniform-grid mixture and LOO minus matched conditional independence. For each sample size, first average each contrast across the nine primary truth-by-range conditions within each root. Then calculate the one-sided t lower bound across the 25 root-level averages (24 degrees of freedom). The four n=18/28 comparisons use the frozen 98.75% lower-bound rule above.
- **Reporting:** preserve every truth, `f0` range, sample size, replicate, and comparator. Report negative controls, the fixed nominal model, the oracle, group means and ranges, and all four primary lower bounds. Do not select a favorable subgroup or describe a positive held-out signal score as therapy benefit.

## Scope and limits

The signals, their links to resistance, and the shared signal parameters are simulator assumptions. The candidate model grid contains the generating anchors, and the estimator is told the generating `f0` range; this is a favorable, correctly specified setting. Patients in a cohort share one signal model, so the method relies on peer signals being available at baseline. This run does not test heterogeneous patient-specific signal mechanisms, real molecular data, longitudinal MRI, clinical measurements, policy utility, or generalization beyond these assumptions. The prior parameter-recovery run showed weak `d` recovery at n=18/28; that remains a reason this test may fail.

Before running, code and protocol hashes will be recorded in the output manifest. If the advancement gate fails, the next step will be to document the failure and assess a different prespecified method; the seed block will not be reused to tune the candidate.
