# Track A Research Plan — Science Fair MD Final

**Track:** A only

**Project title:** Donor-held-out prediction of glioblastoma Core versus Periphery labels from single-cell expression

## Research Question

Will a sparse, donor-balanced expression classifier improve donor-level Core-versus-Periphery prediction over ordinary logistic regression when every test donor is excluded from training?

## Hypothesis

The sparse candidate classifier will produce a lower mean class-balanced area under the risk-coverage curve (AURC) than ordinary L2 logistic regression across the six primary donors. The candidate will also have lower AURC than logistic regression in at least five of the six donors. The study will treat this as a descriptive decision rule, not as an inferential test of superiority. If either condition is not met, the hypothesis will not be supported by this study.

## Procedure

1. **Set the study scope and verify source files.** The project will analyze the frozen six-donor Yu et al. 2020 Core-versus-Periphery study using GEO accession GSE117891. Before analysis, the project will verify the recorded hashes for the protocol, donor list, model code, expression matrix, sample-barcode table, label table, and cell-type metadata snapshot. A missing file or hash mismatch will stop the run. Source files will remain in local storage and will not be uploaded to cloud services.

2. **Map cells, samples, and labels.** The project will join expression-matrix columns to the GEO cell table by exact cell barcode. It will map GEO patient IDs to the corresponding Table S1 patient IDs and cell points by exact identifiers. Table S1 will supply the MRI-marked surgical-point labels: `Tumoral` will define Core, `Peritumoral` will define Periphery, and `Normal` points will be excluded. The project will not infer labels from expression, point-number order, or cell-type annotations. Cells without one unique, source-supported mapping will be excluded and counted.

3. **Apply the frozen donor eligibility rules.** The primary cohort will include GS1, GS2, GS3, GS5, GS6, and GS13. These donors will meet the frozen GBM and IDH1 R132 metadata rule in the donor table. A dash in the Table S1 IDH1 R132 field will mean that no mutation is reported in that field; it will not be described as proof of comprehensive IDH1/2-wildtype status. The project will exclude donors and samples listed as ineligible in the frozen donor table. The run will stop if any primary donor has fewer than 20 quality-controlled cells in either class. The eight-donor sensitivity cohort will not be included in this study.

4. **Filter and transform expression inside each training split.** The project will retain cells with at least 1,000 UMIs and at least 500 detected genes. For each inner or outer training split, it will keep genes detected in at least 5% of training cells, select the 2,000 most variable genes, normalize each cell to 10,000 counts, apply `log1p`, and scale using means and standard deviations fitted on training cells only. It will apply the same gene order and scaling values to validation and test cells. It will not use held-out donor data to fit preprocessing steps.

5. **Evaluate by donor.** The project will use six outer leave-one-donor-out folds. All cells from one donor will stay in that donor’s held-out fold. Within each outer training set, leave-one-training-donor-out inner folds will select model settings, with at least four donors in every inner training split. The random seed will be 20261031. The project will not create test-to-test cell-graph edges.

6. **Fit the candidate and comparison models.** The candidate will use a sigmoid gene-selection gate with L1 regularization, ridge-regularized classifier weights, a smooth worst-donor cross-entropy objective with temperature 0.1, training-only 15-nearest-neighbor graph smoothness, and a training-only neighbor-probability blend. It will use Adam with learning rate 0.001, a maximum of 500 epochs, and early stopping after 25 epochs without inner-validation improvement. Inner-fold mean class-balanced AURC will select settings; fixed grid order will resolve ties. The primary comparator will be ordinary L2 logistic regression with C values 0.001, 0.01, 0.1, 1, and 10. Secondary baselines will include a 15-nearest-neighbor vote, a linear support-vector machine, and gradient-boosted trees. Three prespecified candidate ablations will remove the gene gate penalty, remove graph regularization and neighbor blending, or replace the smooth worst-donor objective with mean donor loss. All models will use the same donor folds and fixed tuning budget.

7. **Run composition and sampling-depth diagnostics.** A cell-type-only diagnostic will use GBmap Core `annotation_level_2` metadata joined to the GEO cells by exact barcode. It will fit an L2 logistic model with C=1 and balanced class weights on outer-training donors only. The project will not use GBmap expression values or cell-type labels as features in the expression classifier. It will compare the cell-type diagnostic with expression models on the same uniquely mapped cells. A point-size diagnostic will use only the `log1p` number of cells in each sampling point, with an L2 logistic model fitted on outer-training donors. This will check sampling-depth signal, not serve as a biological predictor. Within-cell-type balanced accuracy will be reported only for a cell-type stratum with at least 10 cells from each class in at least four donors.

8. **Calculate the frozen outcomes.** The primary outcome will be class-balanced AURC for each donor. The project will calculate balanced class risk at every retained-cell count from `ceil(N/2)` through N and integrate over the actual coverage values with the trapezoid rule; lower AURC will be better. Secondary outcomes will be full-coverage balanced accuracy and Brier score. The project will report every donor’s values, the equal-donor mean, and the donor range. It will not treat cells as independent donors or calculate p-values for superiority.

9. **Apply the interpretation and reporting rules.** The project will describe the candidate as better than logistic regression only if the candidate has lower donor-mean AURC and lower AURC in at least five of six primary donors. If the cell-type-only diagnostic is within 0.05 balanced-accuracy points of the best expression model on the same mapped cells, the project will report comparable prediction from measured cell-type composition; it will not claim that composition explains the expression result. If no cell-type stratum meets the minimum sample rule, the within-cell-type check will be reported as not possible. A constant-score fold for the SVM or point-size diagnostic will be identified as a constant-score control. The project will report negative and mixed findings without changing the cohort, metrics, thresholds, or success rule after scoring.

10. **State the limits.** The target labels will represent author-supplied MRI-marked sampling points, not histology labels assigned to individual cells. The analysis will include mixed tumor and peritumoral cells, and sampling point will remain nested within region and donor. The project will not claim malignant-cell-specific biology, causation, equivalence, clinical use, or independent external validation. It will report only within-cohort donor-held-out prediction for this dataset.

## Materials Required

- **Computer:** Dell 16 Plus DB16250 with Windows 11, 32 GB RAM, an 8-thread CPU setting, and CPU-only PyTorch. No GPU or physical laboratory materials will be required.
- **Python and libraries for the frozen A5 scoring run:** Python 3.14.4; NumPy 2.5.1; pandas 2.3.3; scikit-learn 1.9.1; and PyTorch 2.14.0+cpu. The scoring code will also use the Python standard-library modules `csv`, `gzip`, `hashlib`, `json`, `math`, `os`, `platform`, `subprocess`, `sys`, `time`, `warnings`, `dataclasses`, `datetime`, `pathlib`, and `typing`.
- **Supporting libraries from earlier Track A audits:** h5py and SciPy (`scipy.sparse`) will be listed for the separate donor-table and composition-audit scripts. They will not be part of the frozen A5 scoring environment.
- **Primary expression dataset:** Yu et al. 2020, NCBI GEO GSE117891, including `GSE117891_all_6148.umi.count.matrix.tsv.gz` ([GEO record](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE117891)).
- **Label and mapping records:** the GSE117891 sample/barcode workbook and Yu et al. 2020 Supplementary Table S1, which will map cells to points and points to MRI-marked Core or Periphery labels ([source paper](https://doi.org/10.1093/nsr/nwaa099)).
- **Composition-diagnostic metadata:** the GBmap Core `annotation_level_2` cell-type metadata snapshot from the [CELLxGENE collection](https://cellxgene.cziscience.com/collections/999f2a15-3d7e-440b-96ae-2c806799c08c). This will be metadata only; the GBmap expression object will not be used.
- **Prior Track A datasets:** the UCSC Cell Browser `multiomic-gbm` atlas and Ivy GAP will be identified as prior exploratory Track A data. They will not be inputs to this frozen six-donor analysis and will not count as independent external validation. Metadata-only screens of other candidate cohorts will not be treated as expression datasets used in this analysis.
- **Storage:** local project storage for source files, metadata, code, and aggregate results. Patient-level or source-derived files will not be uploaded to cloud services.
