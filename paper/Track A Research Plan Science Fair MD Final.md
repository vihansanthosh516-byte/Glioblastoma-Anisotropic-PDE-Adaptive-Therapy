# Research Plan — Donor-Held-Out Prediction of Glioblastoma Core versus Periphery

**Study status:** The computational analysis is complete. This plan will specify how another researcher can reproduce the same run using the original code and complete input bundle. The plan text alone will not reproduce numerical results.

## Research Question

Will a sparse, donor-balanced expression classifier improve donor-level Core-versus-Periphery prediction over ordinary logistic regression when every test donor is excluded from training?

## Hypothesis

The hypothesis will be that the candidate classifier achieves lower mean donor-level class-balanced area under the risk-coverage curve than ordinary L2 logistic regression and lower risk-coverage area in at least five of six donors. The hypothesis will be supported only if both parts of this rule are met. This will be a prediction hypothesis, not a claim about malignant-cell-specific biology or causation.

A newly written implementation based only on this prose will not count as exact reproduction.

2. **Use the fixed donors and region map.** The primary cohort will contain GS1, GS2, GS3, GS5, GS6, and GS13. Eligibility will use glioblastoma histology and the reported `IDH1 R132` field; this field will not be treated as comprehensive IDH1/2-wildtype evidence. GEO patient IDs `S1`, `S2`, and so on will map to paper IDs `GS1`, `GS2`, and so on. Cell-table point IDs will join to Table S1 by exact patient and point identifiers only. The fixed point map will be:

   | Donor | Core (`Tumoral`) points | Periphery (`Peritumoral`) points |
   |---|---|---|
   | GS1 | P1, P4, P5, P6, P7 | P2, P3 |
   | GS2 | P1, P2, P4 | P3 |
   | GS3 | P2, P3, P4, P5, P6, P7 | P1, P8 |
   | GS5 | P1, P2, P3, P4 | P5 |
   | GS6 | P1, P2, P3, P4 | P5 |
   | GS13 | P4, P5, P6 | P1, P2, P3 |

   `Tumoral` points will be labeled Core, `Peritumoral` points Periphery, and `Normal` points excluded. These labels will identify MRI-marked surgical sampling points; they will not be treated as histology labels for individual cells. Point numbers will not be used to infer labels. Numeric class encoding will be Periphery = 0 and Core = 1.

3. **Join cells and apply quality control.** Matrix cell barcodes will join to the GEO cell table by exact barcode. Donor and region labels will then be assigned by the fixed point map. Duplicate barcodes, duplicate gene identifiers, conflicts between patient/point metadata, and conflicts between Table S1 and the donor map will stop the run. Raw counts will be required to be finite, nonnegative integers. Cells will be retained only with at least 1,000 unique molecular identifiers and 500 detected genes. The reproduced run will be checked against the recorded flow: 75 labeled sampling points, zero unmapped target points, zero unlisted target points, 4,139 matched target cells passing quality control, and 2,519 cells from the six primary donors. It will exclude 54 Normal-point cells and 1,955 cells from other patients. Each donor will need at least 20 cells in each region; the recorded smallest region count is 35 Periphery cells for GS5. The eight-donor sensitivity analysis will not be run.

4. **Preprocess separately inside each training split.** In every inner and outer training split, genes detected in at least `ceil(0.05 × training-cell count)` cells will be retained. Each cell will be normalized to 10,000 counts and transformed with `log1p`. Genes will be ranked by population variance on training cells only; ties will be resolved by ascending gene identifier. The 2,000 highest-variance genes will be kept. Training-cell means and population standard deviations will be used for scaling; a zero standard deviation will be replaced by 1. The same gene order and transform will be applied to validation or test cells. No held-out donor data will contribute to feature selection or scaling.

5. **Separate donors for model selection and testing.** Six outer leave-one-donor-out folds will be run in the order listed in `donors.tsv`. In each outer fold, one donor will be held out for testing; inner tuning will then hold out each of the other five donors once, leaving four donors for each inner fit. All cells from one donor will stay in one fold. The held-out test donor will not be used for preprocessing, feature selection, tuning, early stopping, or fitting. Test cells will have no graph edges to other test cells. The seed will be `20261031`. One shared deterministic rank will be assigned to each cell by sorting SHA-256 digests of the seed, a null byte, and the exact cell identifier; the same ranks will be used for every model and fold. The run will use CPU computation, up to eight threads, one PyTorch inter-operation thread, and deterministic PyTorch algorithms.

6. **Fit the candidate model and comparators with fixed settings.** The candidate will be a two-class linear classifier with one sigmoid gate per gene. For standardized feature vector `x`, gate logits `a`, weight matrix `W`, and bias `b`, logits will be `W[x ⊙ sigmoid(a)] + b`. Gate logits and biases will start at zero; weights will use Xavier-uniform initialization. Per-donor cross-entropy will be calculated as the mean cell loss within each training donor. The smooth worst-donor loss will be `0.1 × [logsumexp(donor_loss / 0.1) − log(number_of_training_donors)]`. The full objective will add `lambda_1 × sum(gates)`, `0.5 × lambda_W × sum(W²)`, and `lambda_2 × sum((p_i − p_j)²) / number_of_graph_edges`. The graph will be the sorted unique undirected union of each training cell's 15 nearest training cells by cosine similarity of standardized features; similarity ties will use the shared deterministic cell rank. The graph will use training cells only. Adam will use learning rate 0.001. Inner fits will monitor pooled validation cross-entropy of the unblended classifier output, stop after 25 epochs without an improvement greater than `1e-12`, or stop at 500 epochs, and retain the earliest best epoch. Outer refits will use the median best epoch selected across inner folds.

   The candidate tuning grid will use `lambda_1` and `lambda_2` values `{0.0001, 0.001, 0.01, 0.1, 1}`, `lambda_W` values `{0.001, 0.01, 0.1}`, neighbor temperatures `{0.1, 0.25, 0.5, 1}`, and blend weights `gamma` `{0, 0.25, 0.5, 0.75, 1}`. The 75 regularization settings and 20 temperature/blend settings will be selected jointly by mean inner-donor AURC. Neighbor probabilities will use the 15 closest training cells by cosine similarity and softmax weights `softmax(similarity / temperature)`; the final probability will be `(1 − gamma) × model probability + gamma × neighbor probability`. Ties within `1e-12` of minimum inner AURC will select the first setting in ascending grid order. Three ablations will also be fitted and tuned independently: (a) no feature gate (`lambda_1 = 0`, with `lambda_2`, `lambda_W`, temperature, and blend weight on their full grids), (b) no graph penalty or neighbor blend (`lambda_2 = 0`, `gamma = 0`, with `lambda_1` and `lambda_W` on their full grids), and (c) mean-donor rather than smooth worst-donor loss, with all regularization and blend settings on their full grids.

   Ordinary L2 logistic regression will be the primary comparator, using `C` `{0.001, 0.01, 0.1, 1, 10}`, `lbfgs`, no class weighting, and a 1,000-iteration limit. Secondary comparators will be a uniform-vote 15-nearest-neighbor classifier using cosine distance, a linear support-vector machine with the same `C` grid, squared-hinge loss, no class weighting, and a 10,000-iteration limit, and gradient-boosted trees with 100 estimators, depth 2, minimum leaf size 10, full subsampling, log-loss, no internal early stopping, and learning-rate grid `{0.05, 0.1, 0.2}` using seed `20261031`. Tuned comparator settings will be selected by mean inner-donor AURC; ties within `1e-12` will select the first setting in ascending grid order. For the support-vector machine, each inner-training set will generate donor-held-out margins by leaving out each training donor in turn. A logistic calibrator (`C=1`, `lbfgs`, 1,000 iterations) will fit those margins with equal total weight per donor; the final support-vector machine will then fit all current training donors. This calibration will remain nested inside each inner training split.

   Two diagnostics will use the same outer folds: (a) an L2 logistic model (`C=1`, balanced class weights) using one-hot `annotation_level_2` labels joined by exact cell barcode and scored only on uniquely mapped cells; and (b) an L2 logistic model (`C=1`, balanced class weights) using only `log1p` of the number of quality-controlled cells in that point. Neither diagnostic will be treated as a biological predictor. A within-cell-type check will require at least 10 Core and 10 Periphery cells in at least four donors for each cell type. Every model will use the same outer folds and fixed inner tuning budget.

7. **Calculate endpoints and apply the prespecified rule.** Class-balanced area under the risk-coverage curve (AURC) will be calculated separately for each held-out donor. Cells will be sorted by confidence, `max(p_Core, p_Periphery)`, with the shared deterministic tie rank. At every retained-cell count from `ceil(N/2)` through `N`, risk will be the mean of Core error and Periphery error; if a retained set lacks one class, that class's error will be set to 1. The curve will be integrated with the trapezoid rule over actual coverage values `k/N`. Lower AURC will be better. Donors will receive equal weight in the cohort mean. Secondary endpoints will be balanced accuracy at probability 0.5 and per-donor Brier score. Every donor-level outcome will be retained; no p-value will be used to claim superiority. The hypothesis will pass only if candidate mean AURC is lower than logistic regression and the candidate wins in at least five of six donors.

   **Reference output for the reproduction check:** The recorded candidate mean AURC is 0.1478656 versus 0.1763646 for logistic regression. The candidate wins in GS1, GS2, GS5, and GS6 and loses in GS3 and GS13. The five-of-six rule therefore fails, so the hypothesis will not be considered supported. Candidate Brier score is 0.2335 versus 0.1944 for logistic regression. The no-gate ablation has slightly lower mean AURC than the candidate (0.1472743 versus 0.1478656). Candidate and logistic balanced accuracy are 0.6786 and 0.6621. Cell-type-only balanced accuracy is 0.6546; the best expression model on the same uniquely mapped cells is 0.6789, a difference of 0.0243. This meets the prespecified 0.05 rule for comparable prediction from measured cell-type composition; it does not show that composition explains the expression result. Only the Myeloid stratum meets the within-cell-type size rule, with five eligible donors. The linear support-vector machine is a constant-score control in all six donors. The point-size diagnostic is a constant-score control in GS1, GS2, GS3, and GS5, and varies in GS6 and GS13. These controls will not establish cell-intrinsic biology.
