# Spatial dataset metadata crosswalk

2026-10-30. This is a source and metadata check, not an expression analysis or a held-out test.

The [Zenodo release](https://zenodo.org/records/20709378) lists its files as open access under CC BY 4.0. Its `CNV_scores_per_spot.csv` is 3,761,667 bytes; the downloaded file matched the release's MD5 `b59fa5eaf5ef282878373c9f730d57f7`. Its fields include dataset, barcode, Sample and Patient, plus expression-derived CNV class and scores. The audit inspected identifiers and metadata only; it did not use CNV scores as histology labels or assess expression.

The file has 41,863 spot rows, 22 samples and nine values of Patient. Each sample maps to exactly one Patient value. Each dataset–barcode pair is unique in this file. Independently normalized and checked against the [author sample metadata](https://raw.githubusercontent.com/Petti-Lab/GBM_Spatial_paper_figures_code/main/Figure_2/spatial_data_metadata.txt), each of the 22 samples joins to a sample-name entry; additional metadata rows are absent from the spot file. These are source-provided Patient groups. Identifier aliases need explicit handling: for example [BioSample SAMN54992651](https://www.ncbi.nlm.nih.gov/biosample/SAMN54992651) identifies sample ST073021-2 with isolate B189, while the CNV table gives Patient ST073021. The complete donor-identity mapping remains to be checked before treating the groups as independent patients.

Restricting to the 22 samples and only the metadata's exact biopsy-level `core` and `edge` strings, five Patient groups have at least one sample of each type: B186, ST073021, WU1220, WU1221 and WU1227. B185's metadata table lists an edge sample, but that sample is absent from the 22-sample spot file; its available `intermediate edge` sample was not counted as exact edge. Six apparent core/edge prefixes in the larger sample table therefore reduce to five represented groups in this file. Intermediate, uncertain and margin labels were not silently converted to core or edge.

The author code uses a separate sample-to-image map, including `WU1221.Core` and `WU1221.Edge`, while this CSV uses `WU1221.Core2` and `WU1221.Edge1`. Do not directly join those two image-name fields without a validated mapping. The [GEO series](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE318562) describes manual within-sample histological annotation, but this small CSV does not contain those spot-level histology labels. An author-repository file called `spots_to_cells_celltrek_annotations.rds` is described as a cell-to-spot mapping; its contents were not parsed, and its separate reuse terms are unverified. It is not evidence of a histology-label crosswalk.

A second [2026 GBM spatial atlas](https://doi.org/10.1038/s41467-026-69716-2) reports 13 IDH-wildtype GBM patients and has [open CC BY 4.0 data](https://zenodo.org/records/17572905). Its within-spot anatomical assignments used expression signatures and cell-state assignments as well as histology, so those labels are not independent of expression for the locked prediction question. This cohort has also appeared in prior project work, so it is not automatically untouched confirmation. A reported slide-metadata count needs reconciliation with the paper before using it for eligibility.

## Decision

Five source Patient groups with exact core/edge biopsy labels are below this project's six-paired-donor descriptive feasibility threshold, even before resolving identity and within-sample labels. Nine total patients also remain below its ten-donor inferential threshold. This dataset is not cleared for the locked spatial question. Do not represent biopsy labels as spot histology or the same data as fresh confirmation. Continue seeking a source-backed, reusable spot-label crosswalk and sufficient eligible independent donors, or explicitly revise the question and evaluation.
