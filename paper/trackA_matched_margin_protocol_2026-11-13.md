# Track A protocol for matched malignant-cell expression at core and margin

Status: prospective, eligibility blocked. This file fixes the candidate, estimand, and pass rule before any new test expression read. Freeze a cohort manifest, source overlap audit, baseline adapters, feature manifest, and code hashes in a separate commit before opening test expression. This protocol does not authorize a patient-data run until those records exist.

## Question and data

Predict which member of a matched pair comes from the infiltrative margin in previously unseen patients with primary IDH-wildtype glioblastoma. Require independent surgical or pathological region labels, validated malignant-cell calls, donor and specimen crosswalks, and access and reuse terms. Use one core and one margin pseudobulk per donor, summing malignant cells within each region for each prespecified state. Require at least six eligible test donors, following the [existing Track A gate](trackA_novelty_decision_20261101.md). Hold out the entire validation study and screen biological origins against all local prior use and against the derivation cohorts of the fixed panels. Previously used cohorts are eligible for development only. All fitting and tuning use development patients, with grouped inner folds and no test-distribution normalization. Keep every sample from a donor in the same split.

## Candidate

Use within-specimen gene order to form votes. For each gene pair and malignant state, compute the signed change in the order indicator from core to margin, where an expression tie maps to a neutral vote. Use training donors only. Give each donor equal weight within each state. Keep a pair only if the direction of its average change agrees in every prespecified state. Rank by the minimum absolute average change over those states. Break ties by gene symbols. Weight selected pairs equally and orient them using training results. Score each specimen by the mean of its state-specific gene-order votes, with equal state weights. If no pair survives, predict a tie.

Prespecify Neftel AC-like, MES-like, NPC-like and OPC-like state definitions, scoring code and coverage thresholds using development data only. Set the state list, required per-state cell count, train-only gene prefilter, and common assay gene universe before test expression access. Candidate pair counts come from the same fixed tuning grid used for k-TSP, with patient-grouped selection on the primary metric, ties favoring the smaller count. A test donor must meet the frozen cell coverage requirements in every retained state for both specimens. Report attrition. Any cohort below the donor floor stops. Scope is therefore tumors with enough cells in the shared states.

The proposed distinction is feature selection by the weakest state-specific paired reversal, followed by equal-state scoring. Existing methods already cover state balancing and cross-study gene-pair selection. The exact combination is a novelty hypothesis pending full methods and citation checks, particularly for generalized and meta-analytic rank classifiers. See the [prior-art inventory](trackA_regional_prior_art_2026-11-13.md).

## Common benchmark and pass rule

Use the same eligible donor pairs for every comparator. Compute per-donor concordance as one when the margin score exceeds the core score, one-half for a tie, and zero for reversal. Primary score is the unweighted mean across donors. Fix all score orientations from the published definition or development data before test access. Do not score labels inferred from the expression under evaluation.

Required comparisons: all portable fixed regional signatures and conventional classifier families listed in the [prior-art inventory](trackA_regional_prior_art_2026-11-13.md), whose release-specific definitions and train-only adaptations must appear in the frozen manifest. Include a chance score and ablations using pooled malignant cells, and equal-state scoring with pairs selected by average rather than minimum change. Where the original method requires extra modalities, document the input mismatch and benchmark the portable expression score if one exists. An available direct comparator left unfrozen blocks execution.

The candidate passes only if its concordance is strictly higher than every required comparator, and one-sided exact paired sign tests reject equal donor win probability against each of them at the prospective protocol threshold of 0.05 after Holm correction. Omit donor ties from each sign test only. Report every score, paired difference, tie count, and adjusted p-value, including for failures. The tests concern donor wins, while the strict mean rule concerns magnitude as well. Treat a small validation cohort as limited even after a pass. A pass addresses external prediction under the frozen eligibility rules. Absence of a verified cohort is a data gate failure and yields no model result.
