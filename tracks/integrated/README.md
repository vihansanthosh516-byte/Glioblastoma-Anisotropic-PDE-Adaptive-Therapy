# Integrated phase — synthetic bridge across Tracks A, B, and C

## Question

In synthetic glioblastoma-like worlds, will a finite-set dependence-aware minimax treatment controller improve the predeclared utility over a matched finite-set conditional-independence (`d = 0`) controller when both receive the same molecular-like and MRI-like observations and treatment options?

## How the tracks connect

- **Track A** supplies the conceptual molecular-like channel only. The integrated simulation uses a declared synthetic signal-quality grid and does not use observed A5 metrics as resistance-assay accuracy.
- **Track B** supplies no patient-level observations in this phase. A permitted history-only aggregate may inform the MRI-like scale; otherwise it will use a standard-normal baseline score. Later scan readings are generated by the simulator.
- **Track C** supplies the two-compartment growth and treatment-suppression simulator, signal-dependence model, and treatment-policy comparison.
- The patient datasets are never linked. Every molecular-to-resistance connection is a stated simulator assumption.
