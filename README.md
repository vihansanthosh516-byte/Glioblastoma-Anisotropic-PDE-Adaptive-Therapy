# GBM Science-Fair Project

The main project is the earlier glioblastoma work across Tracks A, B, and C. The goal is to organize and improve that work for a local science fair. This repository overview does not set a final research question or claim that the old models were successful.

Start with [START_HERE.md](START_HERE.md), then use the [GBM file guide](science_fair_gbm/README.md).

## Project tracks

- **Track A:** single-cell and spatial data for GBM cell-state or zone prediction.
- **Track B:** longitudinal MRI and mathematical models of tumor growth.
- **Track C:** mathematical simulations of treatment suppression and adaptive therapy.

The tracks use different cohorts and outcomes. The repository does not establish a patient-level link between the molecular atlas and the MRI cohorts. It does not support a single fused multimodal model or a measured patient-specific drug effect.

## Evidence status

Past results include leakage-sensitive Track A classification, inconclusive or negative growth forecasts against simple baselines, and treatment simulations with assumed drug effects. Read [README_STATUS.md](README_STATUS.md), the [old-track audit](paper/codex_audit/old_tracks.md), and the [findings ledger](vault/PAPER_FINDINGS_LEDGER.md) before using any result. The [Track A/B/C improvement backlog](paper/GBM_TRACKS_IMPROVEMENT_BACKLOG.md) records repository-supported weaknesses and upgrade ideas for a future plan.
